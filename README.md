# EscapeMint

Native SwiftUI app for iOS, iPadOS, and macOS.

## Requirements

- Xcode 16.0+
- Swift 6.0
- iOS 17.0+ / macOS 14.0+
- [XcodeGen](https://github.com/yonaskolb/XcodeGen)

## Setup

```bash
# Generate Xcode project from project.yml
xcodegen generate

# Open in Xcode
open EscapeMint.xcodeproj
```
